# Plantillas para Webs

Repositorio personal de plantillas web (HTML/CSS/JS) con imagen de referencia + código fuente. Pensado para tener un catálogo propio del que copiar/adaptar para nuevos proyectos.

## 📁 Estructura

```
plantillas para webs/
├── plantillas/
│   ├── 01-aetheris-voyage/      ← landing cinematográfica espacial
│   │   ├── index.html
│   │   ├── preview.png          ← imagen referencial
│   │   └── README.md            ← descripción + tech + secciones
│   ├── 02-.../
│   └── ...
└── README.md                    ← este archivo (índice global)
```

Cada plantilla vive en su carpeta numerada `NN-slug/` con:
- `index.html` — código completo
- `preview.png` — imagen de referencia
- `README.md` — qué es, qué tecnología usa, qué secciones tiene, cómo usarla

## 🔄 Flujo de trabajo

Para cada plantilla nueva:

1. **Recibir** imagen de referencia + código/prompt
2. **Crear** carpeta `plantillas/NN-slug/`
3. **Guardar** `index.html` con el código
4. **Guardar** `preview.png` con la imagen
5. **Documentar** en `README.md`: tipo, tecnologías, secciones, notas
6. **Probar** en navegador (o panel de preview)
7. **Registrar** en la tabla del catálogo de este README raíz

## 🚀 Cómo abrir una plantilla

La mayoría son HTML estático con CDN — basta con abrir el `index.html` en el navegador. Si alguna necesita servidor:

```powershell
cd "plantillas\01-aetheris-voyage"
npx serve .
```
